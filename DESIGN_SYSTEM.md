# Dual Design System
Modern Luxury: marketing, pricing, public guest menu/cart/checkout. Editorial type, quality food imagery, whitespace, ivory #F8F5EF, forest #173D32, gold #B99A65, charcoal #191B19. Subtle motion, reduced-motion fallback. Guest menu customizable within accessible tokens.

Global Corporate: workspace, admin, cashier, kitchen, stock, finance and staff. White #FFFFFF, cloud #F4F6FA, cobalt #3157D5, navy #152238, emerald #16966A. Clear typography, dense but readable tables, touch targets, light/dark, keyboard navigation, predictable feedback. Kitchen large controls with text status not color alone.

Shared original UniBOS wordmark, semantic tokens, responsive components, error/loading/empty/success states. WCAG 2.2 AA target; test keyboard, contrast, mobile widths and reduced motion. Colors are proposed, logo not final. No copying competitors or representing sample dashboards as live.
