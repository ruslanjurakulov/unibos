# Project constitution
1. Security and tenant isolation are mandatory.
2. Server owns prices, permissions, entitlements and payment state.
3. Financial records are append-only; corrections are compensating entries.
4. No secrets in code or logs; no real customer data in tests.
5. No fake metrics or simulated features represented as live.
6. Premium original design; accessible mobile and desktop.
7. Modular, portable infrastructure; GitHub not runtime dependency.
8. Configurable pricing and limits, versioned and audited.
9. Backups and restoration tested; rollback plans mandatory.
10. Cost budgets and explicit approval for paid actions.
11. Independent review and evidence before release.
12. Legal and provider gates cannot be bypassed.
13. Changes to this constitution require founder approval and recorded rationale.


Mandatory: follow [CONFIDENTIALITY.md](CONFIDENTIALITY.md). Repository is initialized as private; no public deployment authorized.
