# Phase 1 foundation
Use a TypeScript monorepo: apps/{website,workspace,guest,operations,admin,api}; packages/{database,security,billing,integrations,design-system}; infrastructure and tests. Next.js and NestJS; PostgreSQL and Redis. Start with tenant identity and authorization, database isolation and negative cross-tenant tests before menus/orders. Separate development from production. Pin dependencies and commit lockfile; CI lint/typecheck/test/build and security checks before merge. Payment/fiscal integrations sandbox only until verified. No public deploy. This is a proposed implementation sequence, not running code.
